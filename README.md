# AburriaKnittler

App interactiva que procesa imágenes de tejidos para calcular puntos y filas, optimizada con herramientas de accesibilidad para facilitar el tejido en cualquier entorno.

`main` is the GitHub Pages build (static files). Maintainable source lives on the `source` branch.

## Verificación

```bash
npm test
npm run lint
npm run build
```
